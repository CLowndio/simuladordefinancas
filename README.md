# simuladordefinancas
Criei um simulador financeiro que calcula e entrega todos os valores previsíveis para um aporte constante em fundos imobiliários, de acordo com o salário, rendimento da carteira, anos e perfil de investidor, utilizando comandos básicos como VF e PROCV, com planilha de apoio. Também tem um gráfico que muda de acordo com o perfil!
