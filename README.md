# simuladordefinancas
Criei um simulador financeiro que calcula e entrega todos os valores previsíveis para um aporte constante em fundos imobiliários no Brasil, de acordo com o salário, rendimento da carteira, anos e perfil de investidor, utilizando comandos básicos como VF e PROCV, com planilha de apoio. Também tem um gráfico que muda de acordo com o perfil!
PT: [Simulador fianceiroPT.xlsx](https://github.com/user-attachments/files/33883903/Simulador.fianceiroPT.xlsx)
.

I created a financial simulator that calculates and delivers all predictable values for consistent real estate fund investments in Brazil based on salary, portfolio yield, years invested, and investor profile. The project was built using basic Excel functions such as FV (Future Value) and VLOOKUP, along with a supporting data sheet. It also features a dynamic chart that automatically updates according to the selected investor profile!
